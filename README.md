# 💧 Controle de Níveis de Água

Sistema em terminal para monitoramento de reservatório de água utilizando Python 3 e a biblioteca `colorama` para alertas coloridos.


## 📊 Níveis de Alerta

* **Nível 1:** Muito baixo (Crítico) - Vermelho
* **Nível 2:** Baixo - Amarelo
* **Nível 3:** Médio - Verde
* **Nível 4:** Alto - Ciano
* **Nível 5:** Muito alto (Alerta) - Azul
